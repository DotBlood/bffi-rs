# 行为准则

[English](https://github.com/DotBlood/bffi-rs/blob/main/docs/CODE_OF_CONDUCT.md) | [Русский](https://github.com/DotBlood/bffi-rs/blob/main/docs/i18n/ru/CODE_OF_CONDUCT.md) | **[简体中文](https://github.com/DotBlood/bffi-rs/blob/main/docs/i18n/zh-CN/CODE_OF_CONDUCT.md)**

## 我们的承诺

作为成员、贡献者和负责人,我们承诺让每个人都能在不受骚扰的情况下参与
bffi-rs 社区,无论年龄、体型、可见或不可见的残障、种族、性别特征、
性别认同与表达、经验水平、教育程度、社会经济地位、国籍、外貌、种族、
宗教,或性身份与性取向如何。

我们承诺以有助于建设开放、热情、多元和健康社区的方式行事和互动。

## 我们的标准

有助于营造积极氛围的行为示例:

- 对他人表现出同理心和善意
- 尊重不同的意见、观点和经验
- 给予并优雅地接受建设性反馈
- 为自己的错误承担责任,并向受到影响的人道歉
- 以社区利益为重

不可接受的行为示例:

- 使用带有性暗示的言辞或图像,以及性关注或性骚扰
- 恶意挑衅、侮辱或贬损性评论,人身或政治攻击
- 公开或私下骚扰
- 未经明确许可发布他人隐私信息
- 其他在专业环境中可合理视为不当的行为

## 执行

如遇辱骂、骚扰或其他不可接受的行为,可通过 **contact@z2net.com**
向项目团队举报。

所有投诉都将得到及时、公正的审查和调查。

项目维护者有义务尊重举报者的隐私与安全。
